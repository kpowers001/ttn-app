# Partner photos

Photos shown on challenge cards and the featured banner. Referenced from the
`challenges.photo` column in Supabase (path is relative to the web app root),
with the trail gradient as the fallback whenever a file is missing.

| File | Used by | Status |
|---|---|---|
| `bb-barbecue.jpg` | Friday Night Flavors (B&B Barbecue) | needs the interior photo saved here |

Keep files under ~400 KB so cards stay fast on campus data. Landscape crops
work best: cards render at roughly 200×140 and the banner at full width.
